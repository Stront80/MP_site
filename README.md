# Лендинг экскурсовода — доработанная версия

## Состав проекта
- `index.html` — HTML-разметка, CSS и JavaScript с подробными комментариями.
- `*.jpg` — фотографии, используемые на странице.

## Что улучшено
- Более ровная визуальная иерархия: размеры заголовков адаптируются к экрану, сетки и отступы согласованы.
- Адаптивные стили для мобильных устройств и планшетов, в том числе для карточек, формы, подвала и всплывающего окна.
- Видимый клавиатурный фокус, ссылка «Перейти к основному содержимому», поддержка `prefers-reduced-motion`.
- Метатеги description и theme-color.
- Поля формы получили autocomplete и базовые атрибуты доступности; выбор даты в прошлом ограничен.
- Исправлен риск HTML-инъекции в предпросмотре заявки: данные посетителя вставляются через `textContent`, а не через `innerHTML`.
- Комментарии объясняют назначение секций, CSS-переопределений, адаптивных правил и JavaScript.

## Важно перед публикацией
1. Телефон `+7 (999) 123-45-67` выглядит как демонстрационный — замените его на реальный номер и соответствующий `tel:`.
2. Кнопки Telegram и WhatsApp пока не связаны с реальными аккаунтами. В коде оставлено явное напоминание: укажите проверенные ссылки гида.
3. Форма **не отправляет** данные на сервер, в Telegram или в SQLite. Она только показывает локальный предпросмотр заявки. Для настоящей отправки подключите backend или настройте реальный сервис/ссылку для отправки. Не сообщайте посетителю об успешной отправке до подтверждения сервера.
4. Проверьте точность цен, аккредитации, отзывов, обещания ответа за 15 минут и текста о персональных данных. Эти сведения сохранены из исходного макета и требуют подтверждения владельца.
5. Если сайт собирает персональные данные, добавьте корректную политику конфиденциальности и явное согласие в соответствии с применимым законодательством.

## Локальный просмотр
Откройте `index.html` в браузере. Для размещения на GitHub Pages загрузите файлы из этой папки в корень репозитория и включите Pages в настройках репозитория. Все изображения подключаются относительными путями, поэтому отдельный сервер для статической части не нужен.
